
# My First Document

Welcome to the collaborative document editor! This is a sample document that demonstrates the basic formatting capabilities.

## Getting Started

You can create rich text documents with the following features:

### Text Formatting
- **Bold text** for emphasis
- *Italic text* for subtle emphasis
- ~~Strikethrough~~ for deleted content
- `Inline code` for technical terms

### Lists

#### Bulleted List
- First item
- Second item
- Third item with **nested formatting**

#### Numbered List
1. Step one
2. Step two
3. Step three

### Headings
# Heading 1
## Heading 2
### Heading 3

### Quotes and Code Blocks

> This is a blockquote. It's great for highlighting important information or citing sources.
